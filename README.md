## About the course

In Copilot Chat, Word, PowerPoint, Excel, Outlook and Teams, participants turn a synthetic service case into sourced briefs, analysis, meeting actions and leadership messages, checking claims and keeping a human owner for consequential decisions.

Participants then describe a repeatable service process to Copilot Workflows, map its trigger, steps, approval and exception path, and test normal and failure cases. They use Copilot Agent Builder to define a bounded purpose, instructions, approved knowledge and starter prompts, and test the agent before any sharing. Feature availability depends on the organisation's Microsoft 365 tenant; an offline design and test path is provided.

Leaders finish with a pilot cohort, adoption plan, quality and value scorecard, and a board-ready go, hold or stop recommendation. No coding is required. The course is informed by Microsoft AB-730 and AB-731 themes; it is not Microsoft exam preparation.

## Learning outcomes

1. Develop technology implementation plans and business processes for Microsoft Copilot.
2. Develop control procedures for Microsoft Copilot to manage security.
3. Evaluate the integration of Microsoft Copilot to ensure alignment with business objectives.
4. Develop optimization plans for Microsoft Copilot to improve business operations.

## Topics covered

1. Use Microsoft 365 Copilot for everyday business work
2. Design safe Copilot Workflows and human controls
3. Create and test bounded Copilot agents
4. Lead adoption, measure value and scale outcomes
